Tutorial 8: Miscellaneous

This Tutorial demonstrates miscellaneous functions of the SIR3S_Model() class that cannot be assigned to one of the previous Tutorial topics.

SIR 3S Installation

[1]:

SIR3S_SIRGRAF_DIR = r"C:\3S\SIR 3S\SirGraf-90-15-00-24_Quebec-Upd2" #change to local path

Imports

Note: The SIR 3S Toolkit requires the Sir3S_Toolkit.dll included in SIR 3S installations (version Quebec and higher).

[2]:

import sir3stoolkit

The core of sir3stoolkit is a Python wrapper around basic functionality of SIR 3S, offering a low-level access to the creation, modification and simulation of SIR 3S models. In the future pure python subpackages may be added.

[3]:

from sir3stoolkit.core import wrapper

SetLogFilePath()

We can use the function SetLogFilePath() to change where the log file, created when SIR 3S executes calculations, is saved. It takes the full path of the log file, including the file name.

Set_Raise_On_Error()

When the SIR 3S Toolkit is used from a standalone Python process (like this notebook), errors reported by SIR 3S raise a SIR3S_ToolkitError. Inside SIR Graf they are only logged and the function returns a value indicating the failure (e.g. False, ‘-1’ or (‘’, ‘’)). Let’s try to set the log file path to a directory that does not exist.

[28]:

try:
    s3s.SetLogFilePath("C:/does/not/exist/Tutorial8.log")
except wrapper.SIR3S_ToolkitError as e:
    print(f"Caught: {e}")

[2026-10-14 14:12:25,778] ERROR in sir3stoolkit.core.wrapper: Error: DirectoryNotFoundException: Ein Teil des Pfades "C:\does\not\exist\Tutorial8.log" konnte nicht gefunden werden.

Caught: Error: DirectoryNotFoundException: Ein Teil des Pfades "C:\does\not\exist\Tutorial8.log" konnte nicht gefunden werden.

We can use the function Set_Raise_On_Error() to change this behavior: False only logs errors (the behavior inside SIR Graf), True always raises, None restores the default.

[29]:

wrapper.Set_Raise_On_Error(False)
s3s.SetLogFilePath("C:/does/not/exist/Tutorial8.log")

[2026-10-14 14:12:25,811] ERROR in sir3stoolkit.core.wrapper: Error: DirectoryNotFoundException: Ein Teil des Pfades "C:\does\not\exist\Tutorial8.log" konnte nicht gefunden werden.

[29]:

False

[30]:

wrapper.Set_Raise_On_Error(None)

Errors of core calls made inside mantle methods are always only logged, as the mantle handles them itself.

Note that not every invalid input is reported as an error by SIR 3S. Check the stored values with GetValue() (Tutorial 2) and run ExecuteModelValidation() (Tutorial 9) before relying on a model you built or changed.

We can use the function EnableOrDisableOutputComments() to turn output comments on or off. Default is True.

s3s.EnableOrDisableOutputComments(outputComments=True)

[32]:

print(s3s.InsertElement(s3s.ObjectTypes.Node, "-1"))

[33]:

s3s.EnableOrDisableOutputComments(outputComments=False)

[34]:

print(s3s.InsertElement(s3s.ObjectTypes.Node, "-1"))

As you can see, after the output comments were disabled the function does not print an output. The printed tk is the return value of the function that is displayed in Jupyter Notebooks.

AllowSirMessageBox()

We can use the function AllowSirMessageBox() to allow or diallow SIR DB Messages to pop up. Default is True. Generally, not recommeded to turn off, as it could mean missing out on deep error messages.

s3s.AllowSirMessageBox(bAllow=True)
