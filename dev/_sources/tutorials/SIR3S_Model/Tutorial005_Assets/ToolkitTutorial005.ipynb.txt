    "## Connecting Elements Across Containers (Block Connections)"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "6995acb4",
   "metadata": {},
   "source": [
    "Connecting elements can only be connected to nodes in their own container: [AddNewConnectingElement()](https://3sconsult.github.io/sir3stoolkit/references/sir3stoolkit.core.html#sir3stoolkit.core.wrapper.SIR3S_Model.AddNewConnectingElement) and [ConnectConnectingElementWithNodes()](https://3sconsult.github.io/sir3stoolkit/references/sir3stoolkit.core.html#sir3stoolkit.core.wrapper.SIR3S_Model.ConnectConnectingElementWithNodes) refuse an end node in another container.\n",
    "\n",
    "In SIR 3S a block (container) is linked to the surrounding network by a *block connection node* (VKNO, `ObjectTypes.BlockConnectionNode`): the node itself stays in the outer container, the VKNO shows it inside the block, and the connecting element inside the block uses the outer node directly as its end node.\n",
    "\n",
    "With the Toolkit this is done in three steps: create and connect the elements in the main container, move them into the block with `SetValue(..., \"Fkcont\", ...)`, and add a VKNO for each outer node. [Network 3](https://github.com/3SConsult/sir3stoolkit/blob/main/docs/source/networks/Network3.py), the model of the mantle tutorials, connects its heat plant this way."
